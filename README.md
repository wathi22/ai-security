## Wie dieser Vault funktioniert

Dieser Ordner ist **gleichzeitig**:
- ein **Git-Repo** (Version Control von Tag 1)
- ein **Obsidian-Vault** (verlinkte Notizen)

Ein Ordner, zwei Superkräfte. Öffne diesen Ordner in Obsidian → fertig.

```
00_meta/              → Roadmap, Wochenplan, Problem-Log, Fortschritt
01_ai_engineering/    → TEIL 1: KI-Systeme bauen
  notes/              → Feynman-Notizen pro Thema
  projects/           → Portfolio-Projekte (Code liegt in eigenen Repos)
  evals/              → Evaluation-Pipelines (die Senior-Skill!)
02_cybersecurity/     → TEIL 2: Systeme angreifen & verteidigen
  notes/
  labs/               → TryHackMe / HackTheBox Fortschritt
  writeups/           → CTF-Writeups = Portfolio-Gold
03_ai_security/       → TEIL 3: Beide Welten verbinden
  attacks/            → Prompt Injection, Jailbreaks, Data Poisoning
  defenses/           → Guardrails, Policy Gateways
anki_decks/           → Spaced Repetition für Befehle & Syntax
templates/            → Vorlagen für Notizen, Writeups, Projekte
```
